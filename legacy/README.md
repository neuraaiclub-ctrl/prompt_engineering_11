# NEURA Platform — Legacy Prototypes Archive

This directory stores early standalone prototypes and exploratory mockups preserved for design and feature reference.

## Archived Files

- `prototypes/neura-first-clue-prototype.html`
  - Early standalone UI prototype for the Round 1 prompt diagnosis workspace.
  - Contains early inline styles and static mock cases.
  - Superceded by the modular Single Page Application (`index.html` + `js/views/round1-workspace.js` and `js/views/arena-workspace.js`).

- `prototypes/neura-round02-prototype.html`
  - Early standalone UI prototype for the Round 2 challenge execution workspace.
  - Superceded by the unified Prompt Arena workspace (`js/views/arena-workspace.js`).
